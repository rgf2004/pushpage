Support

How to get help with pushpage

Contact us

  • Email: support@pushpage.link for help with your account, pages or connecting an AI agent.
  • Bugs and ideas: open an issue on GitHub.
  • Security problems: security@pushpage.link, please do not post them publicly.
  • Data requests: privacy@pushpage.link (see the Privacy Policy).

pushpage is a small project, so replies can take a few days. Please include the page address or id and, for an agent problem, what your client printed.

Report a page

Anyone can publish on pushpage, and we remove pages that break the Terms of Use (phishing, malware, impersonation, spam). If you see one, click Report in the bar at the top of the page, or write to abuse@pushpage.link with the page address.

Check the service

Open pushpage.link/api/health. If it answers {"status":"UP"}, the service is running and the problem is probably on the client side.

Quick answers

My page disappeared. Pages published without an account (guest mode) are deleted after 30 minutes. Pages from an account are kept for 30 days by default. Sign in to the dashboard to see what is live and when each page expires.

I get "Rate limit exceeded" (429). Guests can publish a few pages per minute per IP address, and accounts have a higher limit. Wait for the time in the Retry-After header and try again.

I forgot my password. Use "Forgot password" on the dashboard sign-in page and follow the emailed link. Resetting the password signs out your sessions and connected apps, but your API keys keep working.

I lost an API key. A key is shown only once. Create a new one in the dashboard under Account and revoke the old one.

How do I connect Claude Code, Cursor or another agent? Follow the MCP setup guide or share HTML from Claude Code. For a quick try with no account, use https://pushpage.link/mcp-guest.

How do I stop an agent using my account? In the dashboard, under Account, remove the app from "Connected apps", or revoke its API key. Both take effect immediately.

How do I delete my account? Email privacy@pushpage.link from the address on the account. See the Privacy Policy for what is deleted.

Running your own instance

pushpage is open source and can be self-hosted. Start with the self-hosting and configuration guides. For questions about your own installation, open an issue on GitHub; help there is best effort. Email support at support@pushpage.link is for the managed service at pushpage.link. To report a security problem in the software, including in a self-hosted install, write to security@pushpage.link.
