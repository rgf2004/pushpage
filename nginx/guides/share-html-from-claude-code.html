Share an HTML page from Claude Code

Claude Code is good at building rich HTML: reports, dashboards, prototypes. Sharing that output is the awkward part. This guide gives Claude a publish step, so you ask for a page and get back a link.

1. Add the MCP server (one command)

pushpage runs a hosted MCP server. In your terminal:

claude mcp add --transport http pushpage https://pushpage.link/mcp-guest

That is the whole setup. Without an API key the server runs in guest mode: Claude can publish pages, and each page is deleted after 30 minutes. Run claude mcp list (or /mcp inside Claude Code) to check that pushpage is connected with five tools.

2. Ask for a page

Describe what you want and tell Claude to publish it:

Build an HTML report comparing last quarter's signups by channel,
then publish it with pushpage and give me the link.

Claude writes a self-contained HTML document, calls the publish_page tool, and replies with a URL such as https://pushpage.link/pages/a1b2c3d4.html. Open it in a browser or send it to someone. The agent returns the link instead of pasting a wall of HTML into the chat.

3. Keep your pages longer with an API key

Guest pages last 30 minutes. For longer retention, and to list, update or delete your own pages through the tools, create an account and an API key:

  1. Sign up at pushpage.link/dashboard.
  2. Open the Account tab, name a key (for example “Claude Code on my laptop”) and create it. The key is shown once.
  3. Re-add the server with the key:
claude mcp add --transport http pushpage https://pushpage.link/mcp \
  --header "Authorization: Bearer pp_your_key_here"

Create a separate key for each agent or tool. Revoking one key never affects the others. The dashboard's Account tab also shows these commands with your new key already filled in.

What Claude can do with it

ToolWhat it doesNeeds a key?
publish_pagePublish an HTML document and return its URL.No (guest pages last 30 minutes)
update_pageReplace the HTML of one of your pages and keep its URL.Yes
list_pagesList the pages you have published.Yes
delete_pagePermanently delete one of your pages by id.Yes
healthCheck that the service is up.No

No MCP? Use the API directly

If you would rather not add a server, the same publish step is one HTTP request:

curl -X POST https://pushpage.link/api/pages \
  -H "Content-Type: application/json" \
  -d '{"html":"<h1>Hello</h1>","title":"Hello"}'

The response contains the page url, its id and when it expires. See the documentation for the full API. There is also an agent skill file that teaches Claude when and how to publish.

Tips for good results

  • Ask for self-contained HTML: inline CSS and JavaScript, and a <title> tag in the head, which becomes the page title.
  • Pages are public. Anyone with the link can open one, so do not publish secrets or private data.
  • Scripts are sandboxed. Pages are served with a restrictive security policy, so a page's JavaScript cannot reach the dashboard or the API.

Common questions

Do I need an account?

Not to try it. Guest mode needs no account and no key. You need an account for longer retention and for listing or deleting pages.

Is it open source?

Yes, MIT licensed. You can self-host it with Docker Compose. See self-hosting.

What if I use Cursor or Claude Desktop?

The setup differs slightly; see the MCP server setup guide.
